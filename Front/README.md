# AfterKey Mobile

Aplicativo móvil para gestionar activos digitales, responsables e instrucciones heredables.

## Tecnología

- Expo SDK 54
- React Native 0.81
- TypeScript 5.9
- AsyncStorage para persistencia del JWT

## Inicio

```powershell
npm install
copy .env.example .env
npm start
```

Configure `EXPO_PUBLIC_API_URL` con la URL del backend alcanzable desde el dispositivo.

## Validación

```powershell
npm run typecheck
```
